Privacy-Preserving Federated and Reinforcement Learning-Based Intrusion Detection System for IoT Devices

Research Team: Cyber-Physical Security & Intelligent Networks Lab
Department of Computer Science and Engineering (CSE 499 Senior Design Project)

1 Abstract & Problem

Abstract: Modern Software-Defined IoT Cyber-Physical Systems (CPS) are highly vulnerable to distributed intrusion attacks (`DDoS`, `Botnet`, `DoS`, `Probing`). Traditional centralized machine learning requires uploading raw network flows to a central cloud, introducing massive privacy risks and network overhead.

Proposed Solution: We present a hybrid Federated Reinforcement Learning (FL + RL) framework. Edge client nodes dynamically detect network attacks locally using Dueling Deep Q-Networks (DQN) and transmit only neural network weights (never raw data) to a central Flower FL server using gRPC FedAvg aggregation.

2 Core Objectives

  • Multi-Class Attack Detection: Accurate classification into `Benign`, `Bot`, `DDoS`, `Dos`, and `Prob`.
  • Edge Adaptation via RL: Local Dueling DQN models evaluate 42 feature dimensions in real-time.
  • Privacy-Preserving FedAvg: 3 non-IID client shards exchange model weights over port 8080.
  • Explainable AI (XAI): Integrated SHAP feature attribution + Groq Llama 3.3 70B explanations.

4 Mathematical Formulation

1. Dueling Q-Network Formulation:

Q(s, a) = V(s) + \Big( A(s, a) - \frac{1}{|A|} \sum_{a'} A(s, a') \Big)

2. Federated Averaging (FedAvg):

w_{t+1} = \sum_{k=1}^{K} \frac{n_k}{N} w_{t+1}^k
